APARTADO INFORMATIVO

Conceptos básicos

¿Qué es la etiqueta <canvas>?

La etiqueta <canvas> de HTML crea una superficie rectangular dentro de una página web en la que se pueden dibujar gráficos mediante JavaScript. Por sí sola, la etiqueta solo proporciona el área de dibujo; el código JavaScript indica qué se dibuja.

Por ejemplo, <canvas width="400" height="400"></canvas> crea un lienzo de 400 píxeles de ancho por 400 de alto. Es importante definir sus dimensiones para controlar el espacio disponible.

Contexto de renderizado 2D

El contexto 2D permite dibujar formas, líneas, texto e imágenes. En JavaScript nativo suele obtenerse con canvas.getContext("2d"). Incluye operaciones para establecer colores, dibujar rectángulos, arcos y modificar el estilo del trazo.

En esta práctica, p5.js administra el lienzo y ofrece funciones más sencillas, como ellipse(), rect(), line(), fill() y background().

Fundamentos de p5.js

p5.js es una librería de JavaScript pensada para facilitar la creación de dibujos, animaciones e interacciones. Traduce acciones comunes de dibujo a funciones fáciles de leer, por lo que es útil para aprender los conceptos básicos de gráficación.

Funciones principales usadas

  • createCanvas(ancho, alto): crea el área de dibujo.
  • background(r, g, b): pinta el fondo usando valores de color RGB.
  • fill(r, g, b): define el color interior de las formas.
  • noStroke() y stroke(): quitan o establecen el contorno.
  • ellipse(x, y, ancho, alto): dibuja una elipse.
  • rect(x, y, ancho, alto): dibuja un rectángulo.
  • line(x1, y1, x2, y2): dibuja una línea entre dos puntos.

En p5.js, las coordenadas empiezan en la esquina superior izquierda: (0, 0). El valor de x aumenta hacia la derecha y el de y hacia abajo. La función setup() se ejecuta al iniciar; draw() puede repetirse para producir animaciones. En esta galería se utiliza noLoop() porque los dibujos son estáticos.
