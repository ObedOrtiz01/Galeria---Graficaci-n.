Fundamentos de Canvas y p5.js

¿Qué es Canvas?

La etiqueta canvas permite crear un área representar gráficos mediante JavaScript.

Sobre esta superficie pueden dibujarse líneas, círculos, imágenes, animaciones e interfaces gráficas.

Fundamentos de p5.js

p5.js es una librería diseñada para facilitar la creación de dibujos y animaciones interactivas.

  • createCanvas()
  • background()
  • fill()
  • ellipse()
  • rect()
  • line()
  • setup()
  • draw()
