# Mi galería de dibujos

Proyecto escolar sencillo para la materia de Gráficación. Usa HTML, CSS, JavaScript y la librería p5.js.

## Archivos

- `index.html`: estructura de la página, menú, proyectos y explicación teórica.
- `styles.css`: colores, distribución y diseño adaptable a celulares.
- `sketch.js`: código p5.js de los cinco dibujos.

## Cómo probarlo en tu computadora

1. Descarga y descomprime la carpeta.
2. Abre `index.html` en un navegador con conexión a internet. p5.js se carga desde una CDN.
3. Usa el menú o los botones para cambiar el dibujo.

## Cómo publicarlo con GitHub Pages

1. Inicia sesión en GitHub y crea un repositorio nuevo, por ejemplo `galeria-graficacion`.
2. Sube los tres archivos principales (`index.html`, `styles.css` y `sketch.js`) y este README.
3. En el repositorio, entra a **Settings → Pages**.
4. En la opción de publicación, selecciona **Deploy from a branch**, elige la rama `main` y la carpeta `/ (root)`, y guarda.
5. Espera a que GitHub Pages publique el sitio. La URL tendrá un formato parecido a `https://TU-USUARIO.github.io/galeria-graficacion/`.
6. Abre la URL en una ventana privada para comprobar que cualquiera puede verla. Esa URL pública es la que debes entregar al profesor.

## Nota

La página necesita conexión a internet para cargar p5.js desde la CDN. El código fuente del proyecto sí está en los archivos del repositorio.
